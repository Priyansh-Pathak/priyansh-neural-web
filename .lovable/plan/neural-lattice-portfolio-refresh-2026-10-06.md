# Neural lattice portfolio refresh

## Goal
Make the existing portfolio more visually distinctive and clearly AI/ML-engineering focused, while retaining its professional restraint and verified content. Remove “student” from all public-facing positioning.

## Visual direction
- Apply the selected Ocean Deep palette with Space Grotesk headings and DM Sans body text.
- Use the selected asymmetric neural-lattice composition: precise grid lines, restrained node motifs, technical metadata, and stronger hierarchy.
- Keep effects subtle and static-first: observer-driven reveals, light hover movement, and reduced-motion support.
- Avoid neon, glow-heavy styling, gradients, particles, glassmorphism, and decorative clutter.

## Changes
- Recompose the hero around “AI/ML Engineer,” stronger project and resume actions, technical evidence, and a refined portrait frame.
- Enrich project cards with visual hierarchy, pipeline-style details, and distinct featured treatment without inventing content.
- Carry the lattice language through About, Experience, Skills, Research, Education, and Contact using lines, indices, and compact technical labels.
- Remove “student” from headings, profile text, metadata, and page/social descriptions while preserving education facts.
- Keep existing links, CV, contact form, theme toggle, and section navigation working.

## Verification
- Check desktop and mobile layouts for clipping, readability, and horizontal overflow.
- Verify section navigation, project/resume actions, theme switching, and CV viewing.
- Confirm the build and browser console remain clean.
